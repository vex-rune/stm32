# CAN 总线

> 整理自项目 `src/16_can_mode_silentI_loopback` 及芯片参考手册。

## 1. 概述

STM32 内部集成 bxCAN（Basic CAN）控制器，支持 CANA 和 CANB 两个独立节点：

- 支持标准数据帧（11 位 ID）与扩展数据帧（29 位 ID）
- 需要外接 CAN 收发器芯片（如 TJA1050）

## 2. 工作模式

bxCAN 有三种正常工作模式：

| 模式 | 说明 |
| --- | --- |
| 初始化模式 | 配置寄存器阶段进入，完成后切换至正常模式 |
| 正常模式 | 收发数据帧的标准工作状态 |
| 睡眠模式 | 降低功耗，可由软件或总线唤醒 |

## 3. 调试模式

三种调试模式用于开发和自测：

### 静默模式（Silent）

- 对外：只接收数据帧，不发送
- 用途：监控 CAN 总线上的通信流量

### 环回模式（Loopback）

- 对外：只发不收
- 对内：自发自收
- 用途：验证发送逻辑是否正常，不影响总线

### 环回静默模式（Loopback + Silent）

- 对外：不发不收
- 对内：自发自收
- 用途：完全独立的自测试，不与外部 CAN 网络产生任何交互

## 4. 帧格式

### 标准帧

- 标识符长度：11 位
- 适用于大多数工业和汽车场景

### 扩展帧

- 标识符长度：29 位
- 支持更大地址空间和更灵活的优先级配置

![标准帧](../src/16_can_mode_silentI_loopback/标准帧.png)

## 5. 接收过滤器

CAN 控制器通过过滤器决定哪些数据帧被接收：

| 模式 | 行为 |
| --- | --- |
| 标识符列表模式 | 仅接收 ID 与列表中完全匹配的数据帧（白名单） |
| 掩码模式 | 按掩码位过滤，只接收 ID 符合掩码条件的数据帧（关键字过滤） |

## 6. 位时序与波特率

STM32 中 CANA 和 CANB 共用同一套位时序寄存器，配置完全相同。

![位时序](../src/16_can_mode_silentI_loopback/位时序.png)

```
波特率 = 1 / 正常位时间
正常位时间 = t_q + t_bs1 + t_bs2
```

- `t_q`：时间量子，由预分频器产生
- `t_bs1`：采样点前的时间段（Propagation Segment + Phase Segment 1）
- `t_bs2`：采样点后的时间段（Phase Segment 2）

合理的 `t_bs1` / `t_bs2` 配置可将采样点放置在位时间的 75%~85% 附近，以提高抗干扰能力。
