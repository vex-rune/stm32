# 曼彻斯特编码与差分曼彻斯特编码

## 1. 概述

曼彻斯特编码和差分曼彻斯特编码都属于**双相码**（Biphase Code），是物理层数据传输的核心编码技术。它们通过电平跳变同时传递数据和时钟信号，解决了数字通信中的**时钟同步**问题。

### 1.1 发展历史

| 年份 | 事件 |
|------|------|
| 1949年 | 曼彻斯特编码由 G.E. Thomas 首次提出 |
| 1970年代 | 差分变种应用于令牌环网 (IEEE 802.5) |
| 现代 | 广泛应用于以太网、RFID、工业总线 |

### 1.2 解决的问题

在曼彻斯特编码出现之前，数字通信使用**不归零编码（NRZ）**：

```
NRZ 问题示例：发送 "00000" 或 "11111" 时
信号: ████████  长时间保持同一电平
结果: 接收端无法分辨这是5个1还是连续的长信号
```

曼彻斯特编码的核心思想：**把时钟信号直接嵌入数据流中一起发送**。

## 2. 曼彻斯特编码（Manchester Encoding）

### 2.1 编码规则

曼彻斯特编码将**每个比特周期的中间**作为分界点，利用**跳变方向**表示数据：

| 数据位 | 跳变方向 | 说明 |
|--------|----------|------|
| **0** | 从高电平跳变到低电平（下降沿） | 前半周期低，后半周期高 |
| **1** | 从低电平跳变到高电平（上升沿） | 前半周期高，后半周期低 |

> **注意**：有些教材定义相反（低到高表示0，高到低表示1），以具体协议为准

### 2.2 波形示意

以数据 `10110` 为例：

```

├─────────────────────────────────────────────────────────────────────────┤

│                                                                         │
│  高电平 ────────────────────────────────────────────────────────────────│
│            ┌─────────┐       ┌─────────┐       ┌─────────┐              │
│  ─────────┘         └───────┘         └─────────┘         └────────────│
│           ↑  ↓        ↑  ↓        ↑  ↓        ↑  ↓        ↑  ↓      │
│           │  │        │  │        │  │        │  │        │  │        │
│  低电平 ─┴──┴────────┴──┴────────┴──┴────────┴──┴────────┴──┴────────│
│                                                                         │
│           ↓  ↑        ↓  ↑        ↓  ↑        ↓  ↑        ↓  ↑      │
│           │  │        │  │        │  │        │  │        │  │        │
│  ────────┐  │        │  │        │  │        │  │        │  │  ──────│
│          │  └────────┘  └────────┘  └────────┘  └────────┘  └───────│
│                                                                         │
├─────────────────────────────────────────────────────────────────────────┤
│  时钟周期:  │──── T ────│──── T ────│──── T ────│──── T ────│        │
│             │    1比特   │    1比特   │    1比特   │    1比特   │        │
└─────────────────────────────────────────────────────────────────────────┘

图解:
  "1" 的规则: 低 → 中间跳变 → 高  (上升沿)
  "0" 的规则: 高 → 中间跳变 → 低  (下降沿)

  特点: 每个比特中心必有跳变，跳变方向表示数据
```


### 2.4 技术特性

| 特性 | 说明 |
|------|------|
| **自同步能力** | 每个比特内部都有跳变，接收端可提取时钟 |
| **直流平衡** | 高低电平各占50%，无直流分量 |
| **带宽需求** | 波特率 = 2 × 比特率（编码效率50%） |
| **典型应用** | 10BASE-T 以太网、RFID ISO/IEC 14443 |

## 3. 差分曼彻斯特编码（Differential Manchester Encoding）

### 3.1 编码规则

差分曼彻斯特编码是曼彻斯特编码的改进版本：

| 数据位 | 编码规则 | 说明 |
|--------|----------|------|
| **0** | 比特开始处发生跳变 | 与前一状态相反 |
| **1** | 比特开始处不跳变 | 保持前一状态 |

> **关键区别**：中心跳变只负责时钟同步，不再表示数据

### 3.2 波形示意

以数据 `10110` 为例（假设初始状态为高）：

```
┌─────────────────────────────────────────────────────────────────────────┐
│                      差分曼彻斯特编码波形                                │
├─────────────────────────────────────────────────────────────────────────┤
│                                                                         │
│  数据位:    1     │     0     │     1     │     1     │     0      │
│             无跳变  有跳变     无跳变    无跳变     有跳变              │
│                                                                         │
│  高电平 ────────┐       ┌───────────────────┐       ┌───────          │
│                 │       │                   │       │                 │
│  ──────────────┘       └───────────────────┘       └─────────────────│
│           ↑       ↑       ↑       ↑       ↑       ↑                 │
│           │       │       │       │       │       │                 │
│  低电平 ─┴───────┴───────┘       └───────┴───────┘                 │
│                 ↑               ↑               ↑                    │
│                                                                         │
├─────────────────────────────────────────────────────────────────────────┤
│  时钟周期:  │──── T ────│──── T ────│──── T ────│──── T ────│        │
│             │ 必有跳变   │ 必有跳变   │ 必有跳变   │ 必有跳变   │        │
└─────────────────────────────────────────────────────────────────────────┘

图解:
  "1" 的规则: 起始无跳变（保持） + 中间必有跳变（时钟）
  "0" 的规则: 起始有跳变（翻转） + 中间必有跳变（时钟）

  特点: 起始跳变有无表示数据，中心跳变只用于时钟同步
```

### 3.3 波形对比图（数据: 11111111）

```
曼彻斯特:     ┌─────┐     ┌─────┐     ┌─────┐     ┌─────┐
                └─────┘     └─────┘     └─────┘     └─────┘
             1  1  1  1  1  1  1  1
             ↑  ↑  ↑  ↑  ↑  ↑  ↑  ↑  (全部上升沿)

差分曼彻斯特:  ────────────────────────────────────────
             无起始跳变     无起始跳变     无起始跳变     无起始跳变
             (全部保持高)   (全部保持高)   (全部保持高)   (全部保持高)
             但中心必有跳变
```

### 3.4 波形对比图（数据: 00000000）

```
曼彻斯特:     ┌┐      ┌┐      ┌┐      ┌┐      ┌┐      ┌┐
                └┘      └┘      └┘      └┘      └┘      └┘
             0  0  0  0  0  0  0  0
             ↓  ↓  ↓  ↓  ↓  ↓  ↓  ↓  (全部下降沿)

差分曼彻斯特:  ─┐ ┌────┐ ┌────┐ ┌────┐ ┌────┐ ┌────┐ ┌────
              ↑↑ ↑↑ ↑↑ ↑↑ ↑↑ ↑↑ ↑↑ ↑  (全部起始跳变 + 中心跳变)
```

### 3.5 技术特性

| 特性 | 说明 |
|------|------|
| **抗极性反转** | 线缆接反时数据不变（差分特性） |
| **抗干扰能力** | 判断跳变有无，而非绝对电平方向 |
| **误码传播** | 单个误码影响1-2个比特后恢复 |
| **典型应用** | 令牌环网 (IEEE 802.5)、磁条卡、工业现场总线 |

## 4. 核心区别对比

### 4.1 波形对比图（数据: 00110011）

```
原始数据:      0     0     1     1     0     0     1     1

┌──────────────────────────────────────────────────────────────────────────┐
│                              曼彻斯特编码                                 │
│                                                                          │
│  规则: 0 = 高→低(↓)     1 = 低→高(↑)   [中心跳变方向 = 数据]          │
│                                                                          │
│  高 ─┐   ┌───┐       ┌───┐   ┌───┐       ┌───┐                      │
│      └───┘   └───────┘   └───┘   └───────┘   └───────                │
│       ↓↑    ↓↑    ↑↓    ↑↓    ↓↑    ↓↑    ↑↓    ↑↓                   │
│                                                                          │
├──────────────────────────────────────────────────────────────────────────┤
│                            差分曼彻斯特编码                               │
│                                                                          │
│  规则: 0 = 起始有跳变    1 = 起始无跳变   [中心跳变=时钟]             │
│                                                                          │
│  高 ─────┐   ┌───────────┐   ┌───────────┐   ┌───────                   │
│          └───┘           └───┘           └───┘                           │
│           ↑↑    ↑↓    ↑↓    ↑↑    ↑↑    ↑↓    ↑↓                       │
│                                                                          │
└──────────────────────────────────────────────────────────────────────────┘
```

### 4.2 一张表记牢

| 对比项 | 曼彻斯特编码 | 差分曼彻斯特编码 |
|--------|-------------|-----------------|
| **数据表示方式** | 跳变方向（上升/下降） | 跳变有无（开始处） |
| **时钟同步点** | 比特中心（强制跳变） | 比特中心（强制跳变） |
| **抗极性反转** | ❌ 差（接反数据全反） | ✅ 好（接反数据不变） |
| **抗噪声能力** | 中等 | 强 |
| **实现复杂度** | 低（直接映射） | 中（需记忆前一状态） |
| **编码效率** | 50% | 50% |

### 4.3 记忆口诀

> **"曼看方向，差看开头"**
>
> - **曼彻斯特** → 看比特中间的电平跳变**方向**
> - **差分曼彻斯特** → 看比特**开始处**有无跳变

### 4.4 共同点

- 每个比特周期中心都有一次跳变（用于时钟同步）
- 高低电平各占50%（无直流分量）
- 编码效率都是 **50%**

## 5. 应用场景

### 5.1 曼彻斯特编码应用

| 场景 | 说明 |
|------|------|
| **10BASE-T 以太网** | IEEE 802.3 标准强制使用曼彻斯特编码 |
| **RFID 标签** | ISO/IEC 14443 Type A/B |
| **红外遥控** | 红外脉冲编码 |
| **汽车 CAN 总线** | 部分汽车网络采用 |

### 5.2 差分曼彻斯特编码应用

| 场景 | 说明 |
|------|------|
| **令牌环网** | IEEE 802.5 标准 |
| **磁条卡** | 信用卡/银行卡磁条编码 |
| **工业现场总线** | PROFIBUS 等老旧工业协议 |
| **部分 RFID** | 某些近场通信协议 |

### 5.3 现代演进

由于 **50%** 的编码效率限制，高速网络已弃用：

| 替代方案 | 效率 | 应用 |
|----------|------|------|
| 4B/5B 编码 | 80% | 100BASE-FX |
| 8B/10B 编码 | 80% | USB 3.0、SATA |
| PAM4 调制 | 100% | 400G 以太网 |
| OFDM | 可变 | 5G、WiFi 6 |

## 6. 解码原理

### 6.1 曼彻斯特解码

```
┌─────────────────────────────────────────┐
│           曼彻斯特解码步骤              │
├─────────────────────────────────────────┤
│                                         │
│  1. 检测比特中心位置的跳变              │
│                                         │
│  2. 根据跳变方向判断数据:               │
│     ┌──────────────────────────────┐   │
│     │   上升沿 → 数据 "1"          │   │
│     │   下降沿 → 数据 "0"          │   │
│     └──────────────────────────────┘   │
│                                         │
│  3. 恢复时钟信号                        │
│                                         │
└─────────────────────────────────────────┘
```

### 6.2 差分曼彻斯特解码

```
┌─────────────────────────────────────────┐
│         差分曼彻斯特解码步骤            │
├─────────────────────────────────────────┤
│                                         │
│  1. 检测比特中心位置的跳变（时钟同步）  │
│                                         │
│  2. 比较当前比特开始与前一比特的电平:   │
│     ┌──────────────────────────────┐   │
│     │   与前一相同 → 数据 "1"      │   │
│     │   与前一不同 → 数据 "0"      │   │
│     └──────────────────────────────┘   │
│                                         │
│  3. 记录当前状态供下一比特使用          │
│                                         │
└─────────────────────────────────────────┘
```

## 7. 例题解析

### 例题

若曼彻斯特编码和差分曼彻斯特编码的波形图如下所示，求实际传送的比特串：

```
┌──────────────────────────────────────────────────────────────┐
│                        波形图                                │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  高 ─┐    ┌────┐   ┌────────┐   ┌────┐   ┌────           │
│      └────┘    └───┘   └────────┘   └────┘                │
│                                                              │
│  低 ─┘        └───┘                                          │
│                                                              │
│      │ 1 │  2  │  3 │  4  │  5  │  6 │  7  │  8 │        │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

### 解题步骤

**曼彻斯特解码**：
```
观察每个比特中心的跳变方向:

  比特1: 中心为 ↓ (高→低) → "0"
  比特2: 中心为 ↑ (低→高) → "1"
  比特3: 中心为 ↓ (高→低) → "0"
  比特4: 中心为 ↑ (低→高) → "1"
  比特5: 中心为 ↓ (高→低) → "0"
  比特6: 中心为 ↓ (高→低) → "0"
  比特7: 中心为 ↑ (低→高) → "1"
  比特8: 中心为 ↓ (高→低) → "0"

结果: 1 0 1 1 0 0 1 0  →  "10110010"
```

**差分曼彻斯特解码**：
```
假设初始状态为高，观察比特开始处有无跳变:

  比特1: 起始↓ (与初始高不同) → "0"
  比特2: 起始无跳变 (保持低) → "1"
  比特3: 起始↓ (与前不同) → "0"
  比特4: 起始无跳变 (保持低) → "1"
  比特5: 起始无跳变 (保持低) → "1"
  比特6: 起始无跳变 (保持低) → "1"
  比特7: 起始↓ (与前不同) → "0"
  比特8: 起始无跳变 (保持低) → "1"

结果: 0 1 0 1 1 1 0 1  →  "01011101"
```
