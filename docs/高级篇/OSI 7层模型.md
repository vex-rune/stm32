# OSI 7 层模型

> 整理自网络基础知识及 ISO/IEC 7498 标准。

---

## 1. 概述

OSI（Open Systems Interconnection，**开放式系统互联**）参考模型是 ISO 国际标准化组织定义的**网络通信标准框架**，将网络通信分为 **7 个层次**。

### 1.1 设计目的

| 目标 | 说明 |
|------|------|
| **标准化** | 不同厂商设备可互联互通 |
| **分层解耦** | 每层只关心自己的职责 |
| **简化开发** | 各层独立设计、独立演进 |

### 1.2 数据传输方向

```
发送方（从上到下）              接收方（从下到上）

  ┌─────────┐                  ┌─────────┐
  │ 应用层  │ ───────────────→ │ 应用层  │
  └─────────┘                  └─────────┘
       ↓                            ↑
  ┌─────────┐                  ┌─────────┐
  │ 表示层  │ ───────────────→ │ 表示层  │
  └─────────┘                  └─────────┘
       ↓                            ↑
  ┌─────────┐                  ┌─────────┐
  │ 会话层  │ ───────────────→ │ 会话层  │
  └─────────┘                  └─────────┘
       ↓                            ↑
  ┌─────────┐                  ┌─────────┐
  │ 传输层  │ ───────────────→ │ 传输层  │
  └─────────┘                  └─────────┘
       ↓                            ↑
  ┌─────────┐                  ┌─────────┐
  │ 网络层  │ ───────────────→ │ 网络层  │
  └─────────┘                  └─────────┘
       ↓                            ↑
  ┌─────────┐                  ┌─────────┐
  │ 数据链路 │ ───────────────→ │ 数据链路 │
  └─────────┘                  └─────────┘
       ↓                            ↑
  ┌─────────┐                  ┌─────────┐
  │ 物理层  │ ───────────────→ │ 物理层  │
  └─────────┘                  └─────────┘
      比特流                      比特流
```

## 2. 7 层模型详解

### 2.1 层次速记口诀

> **"物数网传会表应"**（从下到上）
> **"应表会传网数物"**（从上到下）

### 2.2 各层职责

| 层级 | 名称 | 核心功能 | 数据单位 | 典型协议/设备 |
|------|------|----------|----------|---------------|
| **L7** | 应用层 | 用户接口、网络服务 | 数据 (Data) | HTTP、FTP、DNS、SSH |
| **L6** | 表示层 | 数据格式、加密、压缩 | 数据 (Data) | SSL/TLS、JPEG、MPEG |
| **L5** | 会话层 | 建立/管理/终止会话 | 数据 (Data) | NetBIOS、RPC、SQL |
| **L4** | 传输层 | 端到端可靠传输 | 段 (Segment) | TCP、UDP |
| **L3** | 网络层 | 路由与寻址 | 包 (Packet) | IP、ICMP、ARP、路由器 |
| **L2** | 数据链路层 | 帧传输、差错控制 | 帧 (Frame) | 以太网、WiFi、交换机 |
| **L1** | 物理层 | 比特流传输 | 比特 (Bit) | 网线、光纤、集线器 |

### 2.3 上下层关系

```
┌─────────────────────────────────────┐
│  L7 应用层：HTTP/HTTPS/FTP/DNS/SMTP │
├─────────────────────────────────────┤
│  L6 表示层：SSL/TLS/数据压缩/加密   │
├─────────────────────────────────────┤
│  L5 会话层：会话管理/同步 RPC       │
├─────────────────────────────────────┤
│  L4 传输层：TCP/UDP（端口号）       │
├─────────────────────────────────────┤
│  L3 网络层：IP/ICMP（IP地址）       │
├─────────────────────────────────────┤
│  L2 数据链路层：MAC地址/帧校验      │
├─────────────────────────────────────┤
│  L1 物理层：比特流/电压/接口       │
└─────────────────────────────────────┘
```

## 3. 数据封装与解封装

### 3.1 封装过程（发送）

```
┌────────────────────────────────────────┐
│ 应用数据                                │
│ ┌────────────────────────────────────┐ │
│ │  TCP 头 │ 应用数据                  │ │  ← 传输层封装
│ ├────────────────────────────────────┤ │
│ │ IP头 │ TCP头 │ 应用数据              │ │  ← 网络层封装
│ ├────────────────────────────────────┤ │
│ │ MAC头 │ IP头 │ TCP头 │ 数据 │FCS     │ │  ← 链路层封装
│ └────────────────────────────────────┘ │
└────────────────────────────────────────┘
       ↓
    比特流传输
```

### 3.2 协议数据单元（PDU）

| 层级 | PDU 名称 |
|------|----------|
| 应用层/表示层/会话层 | 数据 (Data) |
| 传输层 | 段 (Segment) |
| 网络层 | 包 (Packet) / 数据报 (Datagram) |
| 数据链路层 | 帧 (Frame) |
| 物理层 | 比特 (Bit) |

## 4. 各层详解

### 4.1 第 1 层：物理层

**职责**：在物理介质上传输**原始比特流**

**关注点**：
- 电压/电流、传输速率
- 物理连接器、线缆规格
- 比特同步、拓扑结构

**典型设备**：集线器（Hub）、中继器（Repeater）、网线、光纤

**典型标准**：以太网（10BASE-T、100BASE-TX）、USB、蓝牙

---

### 4.2 第 2 层：数据链路层

**职责**：在**相邻节点**间可靠传输**帧**

**关注点**：
- MAC 地址寻址（48 位）
- 帧封装、差错检测（CRC）
- 介质访问控制（CSMA/CD）

**典型设备**：交换机（Switch）、网桥（Bridge）

**典型协议**：以太网（Ethernet）、WiFi（802.11）、PPP

**关键概念**：
- **MAC 地址**：物理地址，全球唯一
- **FCS**：帧校验序列

---

### 4.3 第 3 层：网络层

**职责**：实现**跨网络**的**数据包路由**

**关注点**：
- IP 地址（IPv4 / IPv6）
- 路由选择（最短路径、最优路径）
- 分片与重组

**典型设备**：路由器（Router）、三层交换机

**典型协议**：IP、ICMP、ARP、OSPF、BGP

**关键概念**：
- **IP 地址**：逻辑地址，可变化
- **路由器**：连接不同网络的设备

---

### 4.4 第 4 层：传输层

**职责**：提供**端到端**的可靠数据传输服务

**关注点**：
- 端口号（0-65535）
- 可靠传输 vs 快速传输
- 流量控制、拥塞控制

**核心协议对比**：

| 特性 | TCP | UDP |
|------|-----|-----|
| 连接 | 面向连接 | 无连接 |
| 可靠性 | 可靠（重传、确认） | 不可靠 |
| 速度 | 较慢 | 较快 |
| 头部 | 20 字节 | 8 字节 |
| 应用 | HTTP、FTP、邮件 | DNS、视频、直播 |

**关键概念**：
- **Socket = IP + 端口号**
- 常用端口：HTTP(80)、HTTPS(443)、SSH(22)、DNS(53)

---

### 4.5 第 5 层：会话层

**职责**：建立、管理、终止**会话连接**

**关注点**：
- 会话标识
- 同步点（断点续传）
- 通信模式（单工/半双工/全双工）

**典型协议**：NetBIOS、RPC、SQL

> **实际应用**：会话层在现代 TCP/IP 模型中常与应用层融合，作用被弱化。

---

### 4.6 第 6 层：表示层

**职责**：处理数据的**语法和语义**

**关注点**：
- 数据格式转换（ASCII ↔ Unicode）
- 加密解密（SSL/TLS）
- 数据压缩

**典型标准**：JPEG、MPEG、ASCII、SSL/TLS

---

### 4.7 第 7 层：应用层

**职责**：提供**用户接口**和**网络服务**

**典型协议**：

| 协议 | 用途 | 端口 |
|------|------|------|
| HTTP | 网页浏览 | 80 |
| HTTPS | 加密网页 | 443 |
| FTP | 文件传输 | 20/21 |
| SMTP | 邮件发送 | 25 |
| DNS | 域名解析 | 53 |
| SSH | 安全登录 | 22 |
| Telnet | 远程登录 | 23 |

## 5. OSI vs TCP/IP 模型

实际互联网使用的是 **TCP/IP 4 层模型**：

```
┌─────────────────┬─────────────────┐
│   OSI 7 层      │   TCP/IP 4 层   │
├─────────────────┼─────────────────┤
│  L7 应用层      │                 │
│  L6 表示层      │   应用层        │
│  L5 会话层      │                 │
├─────────────────┼─────────────────┤
│  L4 传输层      │   传输层        │
├─────────────────┼─────────────────┤
│  L3 网络层      │   网络层        │
├─────────────────┼─────────────────┤
│  L2 数据链路层  │   网络接口层    │
│  L1 物理层      │                 │
└─────────────────┴─────────────────┘
```

## 6. 通信实例（HTTP 请求）

以浏览器访问 `http://www.example.com` 为例：

```
┌─────────────────────────────────────────┐
│  1. 应用层：HTTP 请求报文              │  → GET / HTTP/1.1
├─────────────────────────────────────────┤
│  2. 传输层：TCP 头（端口 80）          │  → 源端口: 随机, 目标端口: 80
├─────────────────────────────────────────┤
│  3. 网络层：IP 头（DNS 解析得 IP）     │  → 源 IP, 目标 IP: 93.184.216.34
├─────────────────────────────────────────┤
│  4. 数据链路层：以太网帧 + MAC 地址     │  → 通过 ARP 获得下一跳 MAC
├─────────────────────────────────────────┤
│  5. 物理层：比特流通过网线/光纤传输    │  → 电压/光信号
└─────────────────────────────────────────┘
```

## 7. 关键概念总结

| 概念 | 所在层 | 说明 |
|------|--------|------|
| **MAC 地址** | L2 | 物理地址，烧录在网卡，48 位 |
| **IP 地址** | L3 | 逻辑地址，网络可变化 |
| **端口号** | L4 | 区分应用进程，0-65535 |
| **域名** | L7 | 便于记忆的网站名称 |
| **Socket** | L4 | IP + 端口，通信端点 |

### 一句话总结

| 层级 | 功能 |
|------|------|
| **应用层** | 用户能看到的 |
| **传输层** | 端到端的（TCP/UDP） |
| **网络层** | 全网寻址的（IP） |
| **链路层** | 相邻设备的（MAC） |
| **物理层** | 看得见摸得着的（线缆） |
