# 低功耗广域网

## LPWAN 概述

**LPWAN** (Low Power Wide Area Network) 指的是低功耗广域网。

### 核心特点
| 特点 | 说明 |
|------|------|
| **低功耗** | 设备电池可续航数年 |
| **广域覆盖** | 覆盖范围广，通信能耗低 |
| **长距离通信** | 适合大范围区域部署 |

> LPWAN 不是一种技术，而是代表了**所有低功耗广域网技术**。

![alt text](1.png)

### 应用场景
- 智能城市：智能计量、家庭自动化、可穿戴电子、物流、环境监测
- 智能交通、工厂、农业、采矿等领域

---

## LPWAN 技术分类

| 频段类型 | 技术 | 特点 |
|----------|------|------|
| **授权频段** | NB-IoT | 3GPP 主导，采用现有蜂窝网络 |
| **非授权频段** | LoRa、SigFox、ISM | 无需审计、无需申请、无需付费 |

# LoRa 技术

## 概述

- 官网：www.semtech.cn/lora
- **LoRa** (Long Range Communication)，狭义上指物理层的信号调制方式
- Semtech 公司开发，采用**非授权频段**

### 关键指标

| 指标 | 数值 |
|------|------|
| **接收灵敏度** | 148 dBm |
| **传输速率** | 0.3 ~ 50 kbps |
| **市区距离** | 3 km |
| **郊区距离** | 15 km |
| **电池寿命** | 10 年以上 |

### 系统架构
终端节点 → 网关 → 网络服务 → 应用服务

```
LoRa RF -> TCP/IP SSL -> TCP/IP SSL
LoRaWAN -> LoRaWAN    -> Secure Payload
```

---

## LoRa 特点

| 序号 | 特点 | 说明 |
|:----:|------|------|
| 1 | **远距离** | 15 km 通信距离 |
| 2 | **低功耗** | 10 年以上电池寿命 |
| 3 | **安全** | AES128 加密，双向认证 |
| 4 | **标准化** | ISO 标准 (2016.10.1 发布)，LoRaWAN 全球可用 |
| 5 | **地理定位** | 无需 GPS，实现地理定位 |
| 6 | **移动性** | 设备可随意部署或固定安装 |
| 7 | **高性能** | 每个基站可处理 100 万条数据 |
| 8 | **低成本** | 无需申请费用，基础建设成本低 |

# LoRa 通讯关键参数

## 1. 载波频率

**工作范围**：410 ~ 493 MHz

| 常见频段 |
|----------|
| 433 MHz |
| 470 MHz |
| 490 MHz |

---

## 2. 发射功率

- **范围**：22 ~ 25 dBm
- **限制**：低于 1W，不干扰其他频段

> **dBm**（分贝毫瓦）：基于 10 的对数，表示功率相对于 1mW 的级别

---

## 3. 扩频因子 (SF)

**核心参数**：每 1 个原始数据比特被扩展成的码片数量

**公式**：符号长度 = 2^SF 个码片

| SF 影响 | 趋势 |
|---------|------|
| 通信距离、抗干扰能力 | ↑ SF 越大越强 |
| 传输速率 | ↓ SF 越大越慢 |
| 功耗、空中时长 | ↑ SF 越大越高 |

**符号周期公式**：
```
Ts = 2^SF / BW
```

---

## 4. 带宽 (BW)

| 带宽 | 特点 |
|------|------|
| 越大 | 传输速率越高，接收灵敏度越低 |
| 越小 | 传输速率越低，接收灵敏度越高 |

---

## 5. 编码率 (CR)

**作用**：前向纠错 (FEC)，增加校验冗余，纠正空中误码

**公式**：编码率 = 4 / (4 + CR)

| CR 值 | 纠错能力 | 适用场景 |
|-------|----------|----------|
| **CR1** | 几乎无冗余 | 空旷近距离 |
| **CR2** | 中等冗余 | 普通环境 |
| **CR3** | 较强纠错 | 复杂环境 |
| **CR4** | 抗干扰最强 | 强遮挡、工业矿山、电磁复杂环境 |

### 典型组合

| 场景 | 推荐组合 |
|------|----------|
| 远距离 | SF12 + CR4 |
| 近距离电表/水表 | SF7 + CR1 |

---

## 6. 同步字 (Sync Word)

| 属性 | 说明 |
|------|------|
| **位置** | 前导码后的 2 个 chirp 符号 |
| **作用** | 精确定时同步 + 网络识别过滤 |
| **匹配规则** | 收发端必须完全匹配，否则硬件直接丢弃 |

### 帧结构顺序
```
前导码 Preamble → 同步字 Sync Word → SFD 帧起始分隔符 → Header → Payload
```

---

## 7. 前导码 (Preamble)

| 属性 | 说明 |
|------|------|
| **作用** | 信道检测、粗同步、唤醒接收机 |
| **长度** | 常用 8 ~ 12 符号 |
| **匹配规则** | 收发端必须完全匹配 |

---

# LoRa 核心参数速查表

| 参数 | 全称 | 取值/单位 | 核心作用 | 性能影响规律 | 典型配置 |
|------|------|-----------|----------|--------------|----------|
| **SF 扩频因子** | Spreading Factor | SF5 ~ SF12 | 决定通信距离、灵敏度、抗噪能力 | SF↑：距离↑、速率↓、功耗↑ | 远距：SF12<br>常规：SF9<br>近距：SF7 |
| **CR 编码率** | Coding Rate | CR1 ~ CR4 | 增加校验冗余，纠正误码 | CR↑：纠错能力↑、速率↓、功耗↑ | 恶劣环境：CR4<br>普通环境：CR1/CR2 |
| **BW 带宽** | Bandwidth | 125 / 250 / 500 kHz | 决定码片速率 | BW↑：速率↑、灵敏度↓ | 远距离：125 kHz<br>高速短距：250/500 kHz |
| **SyncWord** | Sync Word | 十六进制<br>1~2 字节 | 网络识别 + 时间同步 | 不匹配直接硬件丢包 | 私有：0x12<br>公网：0x34 |
| **Preamble** | Preamble | 8 ~ 12 符号 | 信道检测、粗同步 | 越长越易捕获信号 | 私网：8 符号<br>LoRaWAN：12 符号 |
| **SFD** | Start of Frame Delimiter | 固定 2 符号 | 标记数据开始 | 固定参数，不可配置 | 默认固定 |
