# WIFI 指令

## 设置工作模式指令
```
AT+CWMODE=1
> OK
```

### 工作模式
- 1 : STA模式（Station）
- 2 : AP模式/softAP模式（Access Point）
- 3 : STA+AP模式

| 模式 | 说明 | 应用场景 |
|------|------|----------|
| STA | ESP32作为客户端连接现有WiFi | 接入路由器，同网段设备访问 |
| AP/softAP | ESP32作为WiFi热点发射信号 | 手机/电脑直接连接ESP32 |
| STA+AP | 同时连接WiFi+发射热点 | 桥接功能，转发数据 |

### 区别

| 对比项 | STA模式 | AP/softAP模式 | STA+AP模式 |
|--------|---------|---------------|------------|
| **连接对象** | 连路由器/现有WiFi | 手机/电脑连ESP32 | 同时两者 |
| **IP分配** | 路由器分配IP | ESP32分配IP给客户端 | 双IP |
| **访问方式** | 同网段设备访问ESP32 | 直连ESP32 | 两种方式均可 |
| **上网能力** | 通过路由器上网 | 不能上网 | 通过路由器上网 |
| **典型IP** | 192.168.1.x | 192.168.4.1 | 两个IP |
| **适用场景** | 智能家居、物联网 | 设备配网、局域网控制 | WiFi中继、复杂组网 |

**详细说明：**

- **STA模式**：ESP32作为客户端连路由器，适合固定网络环境。手机/电脑和ESP32在同一WiFi下，通过IP访问。
  - 例：ESP32连家里WiFi，手机在同WiFi下访问ESP32的TCP服务器。

- **AP/softAP模式**：ESP32发射WiFi热点，手机直接连接。无需路由器，但ESP32不能访问互联网。
  - 例：户外无路由器时，手机直连ESP32配置参数。

- **STA+AP模式**：双模共存。AP用于配网/直连，STA用于联网。配网完成后可关闭AP。
  - 例：先用AP模式让手机配置WiFi密码，再切到STA模式联网。
